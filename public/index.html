Como fica em produção

A recepção continua no sistema dela. A conferência entra por trás, sem ninguém precisar lembrar.

Onde roda

Na prova, na Vercel. Em produção, numa VPS no Brasil com o conferente, o banco, o n8n e o Nginx. O aviso sai pela API oficial do WhatsApp, Z-API ou Evolution.

As regras

Cada regra leva a uma decisão só. O número mostra quantas guias de agosto caíram nela. Uma guia pode cair em mais de uma.

Guia repetida

Antes de comparar, as datas são arrumadas: 26/08/2026 e 2026-08-26 são o mesmo dia. Depois, cada guia é comparada com as outras.
O que bateu com outra guiaDecisãoPor quê
Tudo: paciente, dia, procedimento, autorização e sessãoNão enviar assimÉ o mesmo atendimento lançado duas vezes. A primeira vai; a lançada depois é a cópia.
A mesma autorização e a mesma sessão, com outro dado diferenteConferir antes de enviarPode ser uma correção lançada de novo. Alguém decide qual é a certa.
Mesmo paciente (mesma carteirinha), dia e procedimento, outra sessãoConferir antes de enviarPode ser erro de digitação no número da sessão.
Só o código do paciente igualPode enviarCarteirinha e autorização diferentes: são pessoas diferentes.
A mesma guia lançada de novo com o mesmo número conta como correção, não como cópia.

Como o sistema de gestão chama a conferência

O n8n lê as guias novas na API do sistema de gestão a cada poucos minutos e manda cada uma para cá. Se o sistema tiver webhook, ele chama direto. Ninguém precisa lembrar de conferir.
